# Project Guidelines & Rules for iLoveSwap

## Deployment & Version Control Rule
- **Mandatory GitHub Synchronization:** Whenever any deployment, build, or code change is made (e.g., deploying to Vercel, Netlify, or previewing builds), ALWAYS stage (`git add .`), commit with a descriptive message (`git commit`), and push to GitHub (`git push origin main`).
- The GitHub remote repository (`https://github.com/tyranthOM/scamyyy`) must always stay 100% synchronized with the live production deployment on Vercel (`https://scamyyy.vercel.app`).
